# 絵文字SS入力補助ツール

絵文字をキャラに見立てた二次創作SS（ショートストーリー）を、X（旧Twitter）投稿用に手早く組み立てるための入力補助ツールです。

```
#まのさばネタバレ
🌸「こんにちわ」
🖋️「あぁ、エマか」
🌸（やっぱりなんだか緊張するな……）
二人の間に沈黙が流れた。
```

`index.html` 1ファイルだけで動きます。外部ライブラリや外部通信は使っていません。

本ツールは『魔法少女ノ魔女裁判』の非公式ファンメイド作品です。公式とは関係ありません。

AI利用：本ツールのコードは生成AI（Claude）を利用して作成しています。

## 使い方

### 起動
- **ローカル**: `index.html` をダウンロードして、ブラウザで開く
- **Web公開**: GitHub Pages や Netlify などにこのリポジトリを置き、URLを開く

### 入力
1. 種別タブを選ぶ（「」セリフ / （）心の声 / 地の文）
2. キャラボタンを押す（地の文では不要）
3. 本文を入力して **Enter** か **追加** ボタン

キャラと種別の選択は次の入力でもそのまま残るので、同じキャラが続く場合は入力するだけで追加できます。

### 行の編集
- 行をタップすると編集欄が開き、種別・キャラ・本文の変更、上下移動（↑↓）ができます
- セリフ・心の声の行は、編集欄の「」の後ろ」欄で、閉じ括弧の後ろに続ける文を自由に書けます（例: `🌸「見て！」と笑った`）
- 行を選んだ状態で追加すると、**その行の直後に挿入**されます。「✕ 末尾に追加」で選択を解除できます
- PCでは行の左にある `⋮⋮` をドラッグして並べ替えることもできます
- 行の右端の ✕ で、その行をすぐに削除できます。削除した直後は「元に戻す」で取り消せます

### 文字数カウンタ
Xのカウント方法に合わせています（全角文字・絵文字=2、半角文字・改行=1、上限280）。上限を超えると警告色で超過分を表示し、ツイートを何件に分ければよいかの目安も表示します。

### コピー
「📋 全文コピー」で、ハッシュタグ込みの全文をクリップボードにコピーします。自動コピーができない環境では、手動コピー用の画面が開きます。

### 設定（⚙）
- **出力形式**: セリフの「」、心の声の（）を付けるかどうかを切り替えられます（全下書き共通。OFFにすると `🌸こんにちわ` のようになります）。「1行ごとに空行を入れる」をONにすると、本文の行と行の間に空行が入ります（その分文字数は増えます）
- **キャラ定義**: 絵文字・表示名の追加／編集／削除／並べ替え。初期状態は「まのさば」用の13キャラです
- **ハッシュタグ**: チェックがONのタグが本文の先頭に1行で入ります（全下書き共通）
  - 公式ガイドラインに合わせ、`#まのさば` と `#まのさばネタバレ` は同時にONにできません（片方をONにすると、もう片方は自動でOFFになります）
- どちらも「初期値に戻す」で元に戻せます

キャラ定義を変更しても、すでに書いた行の絵文字は変わりません。

### 下書き
- ヘッダーのプルダウンで下書きを切り替えます。＋で新規作成、✎で名前変更、🗑で削除
- 入力や編集のたびに自動保存され、次回は最後に開いていた下書きから始まります

## 注意（データの保存について）

データはブラウザの **localStorage** に保存されます。

- データは **端末・ブラウザ・開き方ごとに別々に管理** されます
  - PCとスマホの間では同期しません
  - 同じPCでも、ブラウザが違えば別データです
  - `file://` で開いた場合と、公開URLで開いた場合も別データです（URLが違えば別データ）
- **ブラウザの閲覧データ（Cookie・サイトデータ）を消去すると、下書きも消えます**
- プライベートブラウズ（シークレットモード）では、ウィンドウを閉じると消えます

大事な作品は、コピーして別の場所にも保存しておくことをおすすめします。


## 対応環境

最近の Chrome / Edge / Safari / Firefox（PC・スマホ）。ライト／ダークモードはOSの設定に合わせて切り替わります。
